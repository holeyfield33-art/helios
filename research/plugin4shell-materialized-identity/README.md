# Research experiment relocated

The Materialized Identity experiment is maintained separately in the standalone
`materialized-identity-lab` repository (initial commit `2dbcbc3`). In the local
workspace it is a sibling directory: `../materialized-identity-lab` from the
product repository root. No public remote has been assigned to that lab yet.

Do not run or extend this experiment inside this product repository. The runner
and fixture data have been removed here. Reproduction instructions, frozen data,
local implementation, limitations, and falsification controls live in the lab.

Helios is implementation ancestry only, not evidence, sponsor, mitigation, or ASI
product coverage. The lab preserves the original license and records the source
commit; its tests and conclusions belong to the neutral research experiment.

External evidence → ASI research question → neutral research experiment → result.
